# ゲムマ2026秋 ブース一覧（非公式）

ゲームマーケット2026秋（2026/10/17 土・18 日、幕張メッセ）の出展ブースを、
**ブース番号順・参加日別・ゲーム名つき**で一覧できる個人用ページです。

- 公式サイトのブース一覧（`https://gamemarket.jp/booth/?target_gm=2026a`）と各ブースの詳細ページを
  C#（.NET 10）のツールで取得して `docs/data/booths.json` にまとめ、GitHub Pages で表示します。
- 取得は GitHub Actions 上で動くので、PC を起動しておく必要はありません。
- スマホで会場を回りながら使う前提の画面です。

## 画面でできること

| 機能 | 説明 |
| --- | --- |
| 参加日 | 「土曜」にすると日曜のみのブース（一般日曜・○○（日曜限定））を除外。初期値は土曜 |
| 検索 | ブース名・ゲーム名・紹介文を検索。ひらがな／カタカナ、全角／半角を区別しない。スペースで AND |
| タイプ | 特設／エリア／一般両日／一般土曜／一般日曜 で絞り込み |
| ☆ 行きたい / ✓ 行った | その端末のブラウザに保存。「★行きたいだけ」「✓行ったを隠す」で絞り込み |
| ★リストをコピー | 行きたいブースをブース番号順のテキストにして、メモアプリ等に貼れる |
| 会場マップ | 一覧の横に地図を常に表示。逆に地図のエリア番号・特設・島を押すと一覧がそのブースへ移動する。ブース番号（📍）を押すと公式のホールマップが開き、その場所が赤枠で光る。特設は公式の「開催場所」画像と照合済み、一般ブースは島単位。位置データは `docs/mapdata.js` に手で入れている |
| 特設の案内 | 特設ブースごとに「種類（展示・試遊・TRPG・マーダーミステリーなど）」と「何ができるか」のひとこと説明を表示。公式紹介文を要約して `docs/specials.js` に手で書いている |
| 特設のサムネイル | 特設ブースに公式サイトのブース画像（小さい版）を表示。画像は公式サーバーのものをそのまま表示し、このリポジトリには保存しない |
| ブロック移動 | ブース番号の頭（特設・エリア・各島）ごとにまとまっていて、上のボタンで飛べる |

## セットアップ（初回だけ・10分くらい）

1. GitHub で新しいリポジトリを作る（例: `gamemarket-viewer`）。このフォルダの中身をそのまま push する。
   ```sh
   git init && git add . && git commit -m "init"
   git branch -M main
   git remote add origin https://github.com/<あなたのID>/gamemarket-viewer.git
   git push -u origin main
   ```
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする。
3. **Actions** タブ → 左の「ブース一覧を更新」→ **Run workflow**。
   - 約1,430ブースを1件ずつ間隔を空けて取りに行くので、初回は 20〜30 分ほどかかります。
   - 2回目以降は新しく増えたブースの詳細だけを取りに行きます（全部取り直すときは `refresh` にチェック）。
4. 終わると `https://<あなたのID>.github.io/gamemarket-viewer/` で見られます。スマホのホーム画面に追加しておくと便利です。

以後は毎日 3:00 (JST) に自動更新されます。イベントが終わったら Actions 画面でこのワークフローを **Disable** してください。

> `?sample=1` を付けて開くと、ダミーデータで画面の動きだけ確認できます。

## 手元の PC で動かす場合

.NET 10 SDK が入っていれば:

```sh
dotnet run --project scraper -- --event 2026a --out docs/data/booths.json
cd docs && python -m http.server 8000   # → http://localhost:8000/
```

オプション: `--no-details`（一覧だけ。数分で終わる）／`--refresh`／`--delay 1000`（ミリ秒）

## うまく取れないとき

公式サイトの HTML の作りに合わせて読み取っているので、サイト側が変わると取れなくなることがあります。

- 実行ログに「ブースを1件も読み取れませんでした」と出たら、そのワークフロー実行の **Artifacts → debug-html** に
  取得した HTML（一覧1ページ目・ブース詳細1件）が残っています。`scraper/Program.cs` の `Parser` クラスを合わせて直してください。
- ブース番号・タイプが空欄になる場合も同じく `Parser.ParseList` を確認。

## 注意

- 非公式のまとめです。最新・正確な情報は公式サイト・公式Webカタログで確認してください。
- 公式サイトに負荷をかけないよう、リクエストは直列・間隔あり・差分取得にしています。間隔を縮めたり頻繁に回したりしないでください。
- 公開リポジトリ＋Pages だと誰でも見られるページになります。公式サイトの[利用規約](https://gamemarket.jp/rule)も確認のうえ、
  気になる場合は URL を人に広めず個人用にとどめてください。
